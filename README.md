# Medical Assistant Community Edition

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-WPF%20%7C%20Windows-lightgrey)

**Medical Assistant Community** is an open-source, lightweight desktop application designed to streamline patient data management and appointment scheduling.

## 🚀 Vision
This is the **Community Edition**. My goal is to build a high-performance, accessible tool for medical professionals. If there is enough interest and a solid user base, I plan to develop a feature-rich "Pro" version including cloud synchronization, advanced diagnostics, and AI integration.

## ✨ Features
*   **Patient Database:** Local, encrypted storage for patient records.
*   **Appointment Manager:** Visual timeline for daily schedules.
*   **Professional UI:** Clean, medical-grade interface built with WPF.
*   **Privacy First:** Data stays on your machine.

## 🛠 Installation
1. Go to the [Releases](waitingformicrosoft) page.
2. Download `MedicalAssistantCommunity.zip`.
3. Extract and run `MedicalAssistantCommunity.exe`.
